## Target architecture

Create an installable `src/partial_cointegration/` package with narrowly scoped modules:

| Module | Responsibilities |
|---|---|
| `model.py` | Parameter/domain definitions, model modes, explicit initialization specification. |
| `filtering.py` | Exact forward filter, optional corrected steady-state approximation, state serialization; no market-data loading. |
| `likelihood.py` | Exact conditional likelihood and explicitly named legacy scoring mode; observable normalization/sign conventions. |
| `estimation.py` | Starting values, multistart fitting, boundary candidates, FitResult and diagnostics. |
| `inference.py` | Negative/positive LR representations, calibration objects and validity metadata. |
| `simulation.py` | Named data-generating designs, independent RNG streams and recovery experiments. |
| `data.py` | Data schema, price/index validation, constituent intervals and point-in-time splits. |
| `signals.py` | Causal continuation, named normalization variants, decisions with timestamps. |
| `execution.py` | Fill policy, signed holdings, cash/fees/borrow ledger and portfolio aggregation. |
| `experiments/` | Configuration-driven reproduction, calibration, sensitivity and empirical evaluation. |

Use a FitResult with named parameters, identified/unidentified status, objective/mode, initial-state assumptions, likelihood, boundary flags and every optimizer status. FilterState must contain timestamp, posterior mean and covariance, and model/configuration identity. CalibrationResult must identify estimator version, initialization, DGP, n, nuisance assumptions, seed, replication count, failed fits and quantile uncertainty.

Keep `Computation`, `partial_cointegration`, and notebook imports as documented compatibility wrappers initially. Their incompatible fit_mle return shapes require separate adapters, not one alias. Remove wildcard imports after adapters pass parity tests. Archives remain historical evidence; do not rewrite them to imply previous outputs were generated by corrected code.
