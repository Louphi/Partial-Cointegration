# Repository cleanup

The active implementation, supported adapters, tests, scientific evidence and original research inputs are retained. Cleanup removes 59 obsolete tracked files (16,748,151 bytes, approximately 16 MiB) from the working tree. It does not rewrite Git history or change the estimator, calibrated scores or strategy.

## Removed files

| Previous path | Reason |
|---|---|
| `archives/` | Unsupported early estimator/strategy/clustering implementations, exploratory notebooks and strategy-specific data copies/caches. Replaced by the active package and configured experiments. |
| `Simulation/Archives/` | Superseded simulation scripts, scratch notebooks, old parameter/LRT outputs and pickle caches. Current checkpointed experiments and measured reports replace them. |
| `Simulation/Outputs/` | Old dated spreadsheets generated by the superseded implementation. They are not corrected-model results. |
| `images/` | Old table screenshots no longer referenced by the current README, notebooks or reports. Current figures live in `docs/results/`. |
| `tools/audit/` | Baseline-only diagnostic scripts that require old production interfaces. Reproduce them from the audit checkout rather than treating them as current tools. The audit evidence and specification remain in `docs/audit/`. |
| `PCI Framework/data/data.pickle` | Undocumented, invalidated fit cache; not a qualified raw-price feed. |
| `PCI Framework/data/allTicker.txt`, `missing_tickers.txt` | Intermediate ticker lists unused by the active workflow. |
| `PCI Framework/FrameworkRDME` | Superseded two-line framework note. |
| `docs/review.md` | First-pass review superseded by the full audit, correction plan, task status and final validation report. |

The application extra no longer directly installs Plotly, which the app does not use. The optional vectorbt engine still pins its required Plotly version. Other declared dependencies remain in use. Ignore rules now cover notebook checkpoints, OS/Office temporary files and package build outputs.

## Preserved

- `src/`, `experiments/`, `tests/`, both supported compatibility folders and the two active notebooks.
- Current validation reports, compact calibration banks, plots, source registers and audit evidence.
- `PCI Framework/data/NasdaqConstituent.csv`, the original constituent source.
- `documentation/PrésentationPCI.pptx`, the original research presentation.
- The working `.venv`, so the documented app and test commands remain usable.
- Ignored completed simulation checkpoints in `.test-deps/studies/` and `.test-deps/paper-study/`, plus downloaded reference sources. These save repeating the expensive studies.

Obsolete local dependency copies, test/type/lint caches and generated scratch fixtures were also removed: 75,241 files totaling 1,541,821,745 bytes (about 1.5 GB), before the small verification caches were regenerated. They are not versioned research inputs. Verification commands can recreate the fixtures and caches they need. Compatibility Excel exporters still create `Simulation/Outputs/` on demand; that generated folder is now ignored.

An additional abandoned 536-file checkpoint set (2,187,976 bytes) from the preliminary failed-estimator run was removed. The final source-matched studies and their committed evidence remain intact.

## Verification after cleanup

- All 193 existing tests passed, with no changes to the active model or tests.
- Both notebooks executed in fresh kernels; synthetic and configured CSV app flows passed, including the short-data error case.
- The app also ran with Plotly and vectorbt imports deliberately blocked, confirming that the application extra does not need them.
- All 12 committed calibration cutoffs and independent rejection counts still match their score banks.
- The refreshed editable installation passed the dependency check. Full Monte Carlo studies were not repeated because their numerical sources and results did not change.
